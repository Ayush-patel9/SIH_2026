1. Scope — Gives the geometrical terms and their definitions relating to twist drills. It also covers 
the different types of twist drills. 

2. Terms and Definitions 

2.1 Twist Drills — An end cutting tool with two cutting edges and having helical flutes for 
admission of coolant and ejection of cutting chips, with a shank for holding and driving. This is 
used for originating or enlarging holes. 

2.2 Axis — The longitudinal centre-line of the drill. 

2.3 Shank — That portion of the drill by which it is held and driven. 

2.3.1 Taper shank ( see Fig. 1 A ). 

2.3.2 Parallel shank (see Fig. 1B).

2.8 Overall Length — The distance between two planes normal to the drill axis through the chisel 
edge ( 2.27 ) and the end of the shank ( including any tenon or tang ) respectively ( see Fig. 1A and 
1B). 

2.9 Flute Length — The distance between two planes normal to the drill axis through the chisel 
edge ( 2.27 ) and the shank end of the flutes respectively ( see Fig. 1A and 1 B ). 

2.10 Flute — A groove in the body of the drill which, at the intersection with the flank (2.22) 
provides a major cutting edge ( 2.24 ), thus permitting removal of chips and allowing cutting fluid 
to reach the major cutting edge ( see Fig. 1A ). 

2.11 Fluted Land — The helical portion of the body (2.6) including both the land (2.15) and the 
body clearance ( 2.18 ) ( see Fig. 1A ). 

2.12 Width of Fluted Land — The distance between the leading edge of the land (2.17) and the 
heel ( 2.20 ), measured at right angles to the leading edge of the land ( see Fig. 1A ). 

2.13 Web — The central portion of the drill situated between the roots of the flutes over the flute 
length ( see Fig. 2 ). 



Note — The point end of the web forms the chisel edge ( 2.27 ). 



2.14 Web Thickness — The minimum dimensions of the web measured in a plane normal to the axis. 
The web thickness is usually measured at the point end.

2.17 Leading Edge of a Land ( Minor Cutting Edge ) — The edge formed by the intersection of a 
land ( 2.15 ) and a flute ( 2.10 ) ( see Fig. 3 ). 

2.18 Body Clearance — The portion of a fluted land reduced in diameter to provide diametral

2.19 Depth of Body Clearance — The radial distance between the land (2.15) and the corresponding 
body clearance ( 2.18 ). It is generally measured at the outer corners ( see Fig 3 ). 

2.20 Heel — The edge formed by the intersection of a flute ( 2.10 ) and the body clearance ( 2.18 ) 
( see Fig. 3 ). 

2.21 Point ( Cutting Part ) — The functional part of the d rill comprised of chip-producing elements. 
The major cutting edges ( lips 2.24 ), chisel edge ( 2.27 ), faces ( 2.23 ) and flanks ( 2.22 ) are there- 
fore, elements of the point ( cutting part ) ( see Fig. 3 ). 

2.22 Flank ( Major Flank ) — The surface on the drill point bounded by the major cutting 
edge ( 2.24 ), the fluted land ( 2.11 ), the following flute and the chisel edge ( 2.27 ) ( see Fig. 3 ). 

2.23 Face — The portion of the surface of a flute adjacent to the major cutting edge ( 2.24 ) and on 
which the chip impinges as it is cut from the workpiece ( see Fig. 3 ). 

2.24 Major Cutting Edge ( Lip ) — The edge formed by the intersection of a flank ( 2.22 ) and 
face ( 2.23 ) ( see Fig. 3 ). 

2.25 Wedge — The portion of the point enclosed between a face ( 2.23 ) and a flank ( 2.22 ) associ- 
ated with the major cutting edge ( 2.24 ). 

2.26 Outer Corner — The corner formed by the intersection of a major cutting edge ( 2.24 ) and the 
leading edge of the land ( 2.17 ) ( see Fig. 3 and 4 ). 

2.27 Chisel Edge — The edge formed by the intersection of the flanks ( 2.22 ) ( see Fig. 3 and 4 ). 

2.28 Chisel Edge Corner — The corner formed by the intersection of a major cutting edge ( 2.24 ) 
and the chisel edge ( 2.27 ) ( see Fig. 3 and 4 ). 

2.29 Chisel Edge Length — The distance between the chisel edge corners ( 2.28 ) ( see Fig. 4 ). 

2.30 Major Cutting Edge ( Up ) Length — The minimum distance between the outer corner ( 2.26 ) 
and the corresponding chisel edge corner ( 2.28 ) of the major cutting edge ( 2.24 ) ( see Fig. 3 ). 

2.31 Drill Diameter — The measurement across the lands ( 2.15 ) at the outer corners ( 2.26 ) of the 
drill measured immediately adjacent to the point ( 2.21 ) ( see Fig. 5 and 6 ). 

2.32 Body Clearance Diameter — The diameter of the body clearance ( 2.18 } behind the lands (2.15) 
( see Fig. 5 ).

2.33 Back Taper— The reduction in diameter ( 2-31 )-from the outer corners ( 2.26 ) towards the 
shank. It is expressed by the ratio of the reduction in diameter and the length of measurement. 

2.34 Web Taper — The increase in web thickness ( 2.14 ) from the point ( 2.21 ) of the drill to the 
shank end of the flutes. It is expressed by the ratio of the increase in thickness and the length of 
measurement. 

2.35 Rotation of Cutting — The primary motion of the cutting edge relative to the workpiece. 

2.36 Right-Hand Cutting Drill ~ A drill that rotates in a clockwise direction relative to the work- 
piece when viewed on the shank end of the drill ( counter-clockwise when viewed on the point end ). 

2.37 Left-Hand Cutting Drill — A drill that rotates in a counter-clockwise direction relative to the 
workpiece when viewed on the shank end of the drill ( clockwise when viewed on the point end ). 

2.38 Lead of Helix — The distance measured parallel to the drill axis ( 2.2 ) between corresponding 
points on the leading edge of a land ( 2.17 ) in one complete revolution of the land ( 2.15 )( see 
Fig. 7). 

2.39 Helix Angle — The acute angle between the tangent to the helical leading edge and a plane 
containing the axis and the point in question. 

Note — Helix angles may be classified as normal, slow and quick.

usually specified and measured at the outer corner.

EXPLANATORY NOTE 

In order to bring \i in line with the work done at ISO level, the Sectional Committee ( EDC 45) 
responsible for preparations of this standard decided to publish a separate standard on terms, 
definitions and types of twist drills which were earlier covered in IS : 5099 'Technical supply condi* 
tions for twist drills'. In the preparation of this standard considerable assistance has been drawn 
from ISO 5419-1982 'Twist drills — Terms, definitions and types 'issued by the International 
Organization for Standardization ( iSO ). 

In comparison with the international standard, tha definitions of twist drills and cutting edge 
height have been given additionally and also the definitions of helix angle has been modified in this 
standard. All the different types of twist drills for which Indian Standards are available have been 
included in this standard.
